# Mecha — apps

Apps y prototipos de **Mecha**, agencia de IA y automatización para PyMEs mexicanas
(Aguascalientes). Todos los datos que traen son de ejemplo.

| Carpeta | Qué es |
|---|---|
| `cubicarga/` | Cubicaje de carga y plan 3D del acomodo |
| `hub-soluciones/` | Escaparate con demos de las soluciones |
| `traba/` | Facturas detenidas: CFDI + evidencia |
| `relevo/` | Conocimiento tácito de la segunda línea, validado con práctica |
| `prende/` | Guía para aprender IA |
| `app/web/`, `app/radar/` | PWA con radar diario para clientes |
| `app/buscador/` | Pedidos manuales: propuesta → aprobación → entrega |
| `plantillas-cliente/` | Bot de WhatsApp, reservas para bares, reportes, scraper de cotizaciones |
| `sitio/`, `parallax/` | Sitio web y landing de Mecha |
| `marca/` | Colores, tipografía y logo |
